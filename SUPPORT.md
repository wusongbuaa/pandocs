# Getting help

- **Questions, and how to do something:** ask in [Discussions](https://github.com/wusongbuaa/pandocs/discussions). Others will have the same question, and the answer stays where they can find it.
- **Something does not work as the documentation says:** open an [issue](https://github.com/wusongbuaa/pandocs/issues/new/choose), with the version and how to make it happen again.
- **An idea:** open an issue with the idea template, or start a discussion if it is still taking shape.
- **A vulnerability:** never in public. See [SECURITY.md](./SECURITY.md).

Start with the documentation: [deploying](./docs/deploying.md), [connecting agents](./docs/connecting-agents.md), [Git sync](./docs/git-sync.md), [importing files](./docs/importing-files.md), [embedding](./docs/embedding.md) and [webhooks](./docs/webhooks.md). A running site has the same and more under **Import the sample documents**.

This is a project run in spare time, with no paid support. Answers come when someone has the time.
