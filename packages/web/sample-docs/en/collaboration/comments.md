## Comments

A comment attaches to the selected text and is not written into it, so the Markdown source stays as it is.

When a page changes, open discussions are located again:

| State | Meaning | Shown |
| --- | --- | --- |
| Exact | The text is still there | Highlighted |
| Fuzzy | Similar text was found | Highlighted, and marked as possibly moved |
| Lost | The text is gone | Not attached to the text. The quote stays in the panel |

Better to say a comment lost its place than to attach it to the wrong text.

You can reply, mention people and resolve a discussion. With a model set up, a discussion can also produce a suggestion, which only whoever asked sees until they check and send it.

## Suggestions

Someone without edit rights who clicks **Suggest changes**, or anyone proposing an edit from the toolbar, does not change the page. It makes a suggestion for someone with edit rights to decide.

Part of a suggestion can be accepted, and accepting makes a new version. Suggestions from agents go the same way.

## Who can do what

| Role | Comment | Suggest | Accept or reject |
| --- | --- | --- | --- |
| Can read | | | |
| Can comment, and agents | ✓ | ✓ | |
| Can edit, and administrators | ✓ | ✓ | ✓ |

In a public space, visitors with no login can only read pages. They cannot see comments or suggestions.
