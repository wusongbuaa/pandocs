---
title: 五分钟上手
---

从启动服务到写好第一页，大约五分钟。你需要一台装了 Docker 的机器。

:::steps

### 启动服务

在项目目录里运行：

```bash
docker compose up
```

第一次运行会构建镜像，PostgreSQL 也会一起启动，不用另外准备。

要让其他机器也能访问，先把 `PANDOCS_URL` 设成它们用的地址，比如 `http://192.168.1.20:8080`。

### 创建管理员

打开 [http://localhost:8080](http://localhost:8080)。第一个打开新站点的人会创建管理员账号。

如果不想把这一步留给先打开的人，可以提前设置 `PANDOCS_ADMIN_EMAIL` 和 `PANDOCS_ADMIN_PASSWORD`。

### 新建空间

空间是一组页面，有自己的目录、成员和回收站。站点还是空的时候，首页就有**新建空间**的按钮。以后要加，点右上角的头像，在**文档管理**里进入**全部空间**。

填好名称和地址，再选“登录用户默认可以”做什么。不确定时选“可阅读”，之后可以在成员里单独给人更高的权限。

### 写第一页

在左侧栏底部点**新建页面**，填好标题就进入编辑器。

输入 `/` 可以插入内容块：提示块、步骤、标签页、流程图、图表都在这里。写完点**保存**，读者看到的就是这个新版本。

### 请人进来

在**用户**里添加同事后，会生成一个设置密码的链接，发给对方就行。它用过一次就失效，有效期 7 天；配置了邮件服务的话，系统也会把它发到对方邮箱。

已经有公司账号体系的话，直接接入 [OIDC 或 OAuth2](./running/people.md)。
