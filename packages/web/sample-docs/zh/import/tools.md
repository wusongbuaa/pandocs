---
title: 从其他工具导入
---

在空间的**导入导出**里选**从其他工具导入**，可以一次搬一批页面。它在后台运行，能看到进度和没搬过来的内容。

页面直接进入空间，不用逐个确认草稿。可以重复运行：同地址的页面内容不同才生成新版本，所以历史里只有之后变化的部分。

:::warning

Notion 和 Confluence 的导入器按工具的文档和其他开源导入器的行为来写，没有用真实的导出文件验证过。飞书只用真实文档验证过内容转换，应用凭证和图片是对着模拟服务测的。第一次导入后请看一下报告。

:::

::::tabs

:::tab[Notion]

在 Notion 导出时选 **Markdown & CSV**，包含子页面，然后上传压缩包，最大 100 MB。大的导出会分成多个文件，逐个导入。

| Notion 里 | 这里 |
| --- | --- |
| 页面和嵌套 | 页面和嵌套。导出不带顺序，所以按字母排序 |
| 页面之间的链接 | 页面移动后仍然有效的链接 |
| 图片和文件 | 保存到这里 |
| 标注和折叠列表 | 提示块和折叠块 |
| 数据库 | 一张包含所有列的表格，下面每行一个页面。视图、公式、关联只保留导出写下的文字 |

:::

:::tab[Confluence]

在空间设置里导出 **HTML** 格式，然后上传压缩包，最大 100 MB。XML 格式不能读取。

| Confluence 里 | 这里 |
| --- | --- |
| 页面树 | 页面树，顺序不变 |
| 代码、信息、提示、备注、警告宏 | 代码块和提示块 |
| 展开宏 | 折叠块 |
| 任务列表和表格 | 任务列表和表格。跨行的单元格会丢失合并关系 |
| 图片和附件 | 保存到这里 |
| 页面之间的链接 | 页面移动后仍然有效的链接 |

作者、评论和页面历史不在这种导出里。

:::

:::tab[飞书和 Lark]

不用导出，通过你创建的应用直接读取文档。

**有编辑权限的人都能把这个应用能读到的内容搬进来**，所以只给它开放你愿意开放的内容。

1. 在开发者后台创建自建应用，添加机器人能力。
2. 开通 `wiki:wiki:readonly`、`docx:document:readonly` 和 `docs:document.media:download`，然后发布版本。
3. 把要读的内容授权给应用：知识库要把机器人所在的群加进成员，单个文档用文档菜单里的添加应用。
4. 在服务器上设置 `PANDOCS_FEISHU_APP_ID` 和 `PANDOCS_FEISHU_APP_SECRET` 并重启。Lark 还要设置 `PANDOCS_FEISHU_BASE_URL=https://open.larksuite.com`。

然后粘贴文档、知识库页面或整个知识库的地址。

| 飞书里 | 这里 |
| --- | --- |
| 文本、标题、列表、待办、引用、代码、公式 | 一样 |
| 高亮块和分栏 | 提示块和分栏块 |
| 表格 | 表格，第一行作为表头。合并的单元格会拆开 |
| 图片和文件 | 保存到这里 |
| 画板 | 一张图片 |
| 电子表格、多维表格、思维笔记 | 页面上的说明和指向原文的链接 |

评论、版本历史和作者不会带过来。

:::

::::

## 把空间导出再导回

**导入导出**还能把整个空间导出成压缩包，导入到这里或者另一个站点。同地址的页面内容不同才生成新版本，同一个包导入两次不会多出版本。
