title: 评论和修改建议
---

选中这段文字试试，旁边会浮出工具条。可以评论、提修改建议、交给模型处理、复制，也可以复制指向这段文字的链接。

点**评论**后右边会打开批注区，所有讨论都在那里。整页的评论写在页面最下方。

:::tip[这一页已经有示例]

导入这份文档时，在这一页生成了一条评论和一条修改建议，可以在页面上方的**评论**和**修改建议**里看到。可以试试回复、接受或拒绝。

:::

## 评论

评论挂在选中的文字上，不写进正文，所以不影响 Markdown 源文件。

页面改了之后，系统会重新定位还没解决的讨论：

| 状态 | 含义 | 怎么显示 |
| --- | --- | --- |
| 精确匹配 | 原文还在 | 高亮 |
| 模糊匹配 | 找到了相似的文字 | 高亮，并提示可能移动过 |
| 找不到 | 原文没了 | 不挂在文字上，引用留在批注区 |

宁可说找不到，也不会挂到错的文字上。

讨论可以回复、@ 别人、标记为已解决。配置了模型时，还能根据讨论生成一条修改建议，结果只给发起的人看，检查后再提交。

## 修改建议

没有编辑权限的人点**建议修改**，或者在工具条里提一处改动，都不会直接改页面，而是生成一条建议，由有编辑权限的人决定。

一条建议可以只接受其中一部分，接受后页面生成新版本。智能体提的建议走的是同一套流程。

这一页下面这句话就是给你试的：修改建议可以逐条接受，接受后生成新版本。

## 谁能做什么

| 角色 | 评论 | 提建议 | 接受或拒绝 |
| --- | --- | --- | --- |
| 可阅读 | | | |
| 可评论，以及智能体 | ✓ | ✓ | |
| 可编辑和管理员 | ✓ | ✓ | ✓ |

公开空间里，没登录的访客只能读页面，看不到评论和修改建议。
