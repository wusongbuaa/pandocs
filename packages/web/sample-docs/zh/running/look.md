## 站点外观

管理员在**站点设置**里可以改：

- 站点标题、描述、徽标和页脚。
- 网站图标：浏览器标签页和书签里的图标，PNG、SVG 或 ICO，最大 16 KB。不设置时用 Pandocs 的图标。
- 品牌色：按钮、链接和选中状态都会跟着变。默认是 Pandocs 的绿色。
- 自定义 CSS：追加到每个页面，用来做主题做不到的调整。

登录页和页面上弹出的登录框是同一种样式，也用站点的徽标、描述和品牌色，跟着浅色或深色切换。单独的登录页不加自定义 CSS。

## 语言

有两件事是分开的。

**界面语言**支持英文和中文。每个人的浏览器决定默认语言，也可以在**账号与令牌**页面单独选。接口按 `Accept-Language` 返回，没有时用英文。

**内容语言**在**站点设置**里打开。每种语言有自己的地址前缀和目录，默认语言之外的页面都在 `/en/` 这样的前缀下面。只有一种语言时不显示切换。

:::warning

新站点默认语言是英文。如果你主要写中文，先去**站点设置**改默认语言，再写内容。

:::

## 标签

标签属于页面，不属于正文，改标签不会生成新版本。页面上方可以加标签，点标签能找到带同样标签的其他页面。智能体可以用 `doc_search` 按标签找。

## 模板

每个空间都可以有自己的模板，新建页面时选。`{{title}}` 和 `{{date}}` 会在新建时填好。之后改模板，不影响已经创建的页面。

## 术语表

每个空间有一份术语表。术语第一次出现时带虚线下划线，鼠标移上去显示解释，不改变正文。也可以从页面里的表格导入，第一列是术语，第二列是解释。

## 反馈

每页最下方都可以投票，也可以留言。说没用或留言的内容，会通知保存当前版本的人，也会进**数据与反馈**。
