---
title: 公开和分享
---

## 公开一个空间

空间管理员可以在空间的**基本信息**里公开这个空间，操作会记入操作记录。

没登录的访客能读这个空间的页面、搜索、看页面用到的图片。其他都是关着的：受限页面、评论、修改建议、历史版本、谁写了什么、其他空间，以及接口描述里没有标记为公开的所有接口。

访客仍然能看到评论、编辑、历史和关注这些入口，在页面顶部、页面底部和选中文字时都有。点了会在当前页面上弹出登录框，登录后接着做刚才选的事，比如直接进入编辑。

| | |
| --- | --- |
| 整站禁止 | `PANDOCS_PUBLIC_SPACES=false`，比如内部部署 |
| 限流 | 每个副本限制同一地址每分钟 600 次请求，其中搜索 120 次。再多就交给 CDN 或防火墙 |
| 看不到的和不存在的 | 没登录的人都得到 404，并提示可能需要登录 |

## 给搜索引擎和智能体

- 页面从服务端出来就是完整的，有标题、描述和分享卡片，还有 `/sitemap.xml` 和 `/robots.txt`。
- 不存在的地址返回 404，移动过的返回 301。
- 智能体可以读 `/llms.txt`、`/llms-full.txt` 和每页的 Markdown，`/mcp/public` 是不用登录的只读 MCP。

## 分享链接

有编辑权限的人可以在页面上方生成链接，让任何人不用登录就能读这个页面，也可以包括子页面，直到链接过期或被撤销。

拿到链接的人只能看到这些页面，看不到站点上其他内容，也不能评论和搜索。受限页面不能这样分享，页面变成受限后，已有的链接马上失效。
