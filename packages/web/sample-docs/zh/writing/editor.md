---
title: 编辑器
---

点页面上方的**编辑**进入编辑器。它是所见即所得的，流程图、图表这些块在编辑器里和阅读时看起来一样，光标移进去才打开源码。

## 常用操作

| 想做什么 | 怎么做 |
| --- | --- |
| 插入内容块 | 在空行输入 `/` |
| 插入图片 | 粘贴或拖进来 |
| 改写、翻译、总结选中的文字 | 选中后在工具条里点**智能辅助**（需要配置模型） |
| 直接改 Markdown | 工具栏里的**编辑 Markdown 源码**，切回来时以写的内容为准 |
| 改标题 | 直接在标题上改，和正文一起保存 |

## 多人同时编辑

编辑同一页面的人共用一份草稿，能看到彼此的输入和光标。不需要 PostgreSQL 以外的组件，连到不同副本的人也一样。

- **读者只看保存过的版本。** 打字不会改变页面。点**保存**会把草稿变成新版本，点击的人是作者，其他人会记在版本说明里。
- **草稿会一直留着。** 离开编辑器不会丢内容。页面上会提示能编辑的人，**我的草稿**里也能看到。不想要了就点**丢弃修改**。
- **撤销只撤自己的。** 不会撤掉别人写的内容。
- **断网不丢内容。** 输入的内容留在浏览器里，恢复连接后自动合并。

:::tip[智能体不进草稿]

智能体和 Git 同步通过接口写入，不加入草稿。它们生成的版本会马上并入草稿，大家能看到内容进来。如果改的是同一处，草稿保留自己的内容并提示所有人，那个版本仍然留在历史里。

:::

## 什么时候不走共享草稿

下面这些情况，每个人用自己的草稿，保存时再合并：

- 提修改建议和翻译，因为产出是个人要提交的内容。
- 空间要求所有改动都走[变更集](../collaboration/change-sets.md)。
- 页面嵌在别的系统里。
- 代理挡住了 WebSocket。编辑器几秒后会提示，然后继续单人编辑。
- 站点设置了 `PANDOCS_LIVE_EDITING=false`。

## 标记有问题怎么办

块写错了不会影响别的内容。有编辑权限的人会在页面顶部看到问题列表，普通读者只在那个块上看到提示。通过接口写入时，返回结果也会带上这些问题，加 `strict=true` 则直接拒绝。
