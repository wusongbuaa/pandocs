---
title: 给智能体用
---

智能体能读、能评论、能提修改建议，但不能自己保存，要由有编辑权限的人决定。它能读到的也不会超过它代表的那个人。

选哪种接入方式，主要看智能体在哪里运行：

| 情况 | 用什么 |
| --- | --- |
| 支持 MCP 的助手 | [连接 MCP](./agents/connect.md)，登录授权就行 |
| 爱读文件的工具，能连上服务器 | [`pandocs sync`](./agents/files.md) |
| 很多沙箱，或者沙箱连不上服务器 | [发布到共享目录](./agents/files.md)，只读挂载 |
| 你自己写的程序 | [接口和客户端库](./agents/api.md) |
| 只是想让它读一下 | `/llms.txt`，或者任何页面地址加 `.md` |

::subpages
